## 是什么

经典玩法：人站在板子上往下掉，板子会托住你，天花板（带锯齿的挤压线）会一直往下压，压到你就没了。左右移动、躲尖刺、踩弹簧，一层层往下，比谁掉得深。

三档难度（简单 / 困难 / 地狱），难度会影响上升速度、陷阱密度和伤害，但**重力、移动速度、层间距保持不变**——操作手感三档一致，只让节奏变狠。

## 技术是怎么搭的

单文件 HTML + Canvas 2D，没有一个外部素材。

- **画面**：所有图形都是代码画的——像素描边矩形、锯齿天花板、砖墙、底纹贴图，`setTransform` 处理像素缩放，保持低分辨率像素感。
- **循环**：`requestAnimationFrame` + `dt` 累积时间，逻辑按固定步长推进，帧率波动不会让物理变快变慢。
- **平台类型**：普通板 / 弹板 / 尖刺板 / 翻转铁板（踩上后翻过去把人漏下去）/ 传送带（必须给横向速度，否则玩家逆着走不动）。
- **生成**：所有平台钉在生成网格上，层间距恒定；横向全宽随机，但要求与上一块错开半个板宽，避免两块叠在一起；浅层不出陷阱，难度按深度因子插值。
- **判定**：尖刺持续掉血、不吃无敌帧；踩弹簧后进入「竖直锁定」，期间锁掉左右输入，保证是真起跳而不是斜着弹。
- **存档**：`localStorage` 按难度分别存纪录，互不污染；难度选择也读回上次的选择。
- **音效**：Web Audio 现场合成，不加载音频文件。
- **输入**：键盘 + `touchstart`，手机上也能玩。

## 踩到的坑

- **穿模**：最早只判「矩形相交」，从侧面也能站住。改成「上一帧在板面上方、这一帧穿过板面」才算落地。
- **天花板挤压线**：线以上的板子必须一律不能站，否则会被抬到压扁，判定要单独拦一道。
- **画布点击误触**：开始界面点画布会跳过难度选择，后来限定只有结束界面点画布才能重开。
- **难度表**：一开始连重力和速度一起调，结果三档手感完全不是同一个游戏，最后收回到「只调节奏、陷阱密度、伤害」三项。
