## 问题

通用的聊天助手说话太「标准」：四平八稳、每句都想周全，不像我。我想做一个数字分身，用来回答那些被反复问到的问题——它得先像我，才可能有用。

难点不在生成，在「像」这件事怎么被验证。我的判断标准很土：把它的回答和我自己以前说过的话混在一起，让同学挑，看能不能挑出来。

## 做法

按设计图从零搭了整页聊天界面，然后才开始调「人格」。

- 语料只用我自己写过的东西：课程笔记、朋友圈长文、发给同学的解释
- 提示词分三层：身份、说话习惯（短句、少用感叹号、先给结论）、禁区（不替我做承诺）
- 上下文按「最近 6 轮 + 一条长期摘要」管理，超了就压成摘要，不硬塞
- 前端对话气泡做成流式输出，滚动到底部用 `scrollTop` 补间，避免每帧跳动

```js
// 流式输出时不要每来一个字就滚一次，攒一帧再滚
const stick = () => {
  const nearBottom = el.scrollHeight - el.scrollTop - el.clientHeight < 80;
  if (nearBottom) requestAnimationFrame(() => (el.scrollTop = el.scrollHeight));
};
```

## 结果

第一版交互生硬：答案一口气刷出来、气泡高低不齐、滚动手感像被拽着走。听了同伴反馈后重做了气泡的进入节奏和滚动策略，观感才勉强过关。

- **语料**：约 4 万字个人文本
- **盲测**：5 个同学，平均 6 次里挑对 4 次
- **最像的地方**：先给结论、爱用「其实」开头
- **最不像的地方**：遇到不确定时会绕，我不会

## 还没解决的

它太爱解释自己为什么这么答。真实的我通常一句话说完就跑了——下一步想把「解释」也纳入风格约束，而不是只在提示词里写一句「简洁」。
