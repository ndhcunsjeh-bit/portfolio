本地双击 HTML 一切正常。传到 GitHub Pages，打开是白屏。

第一轮排查：样式没了。原因是路径写成了 `/style.css`（从根目录找），而站点其实在 `/random-lunch/` 下面，应该用相对路径或者带上仓库名。

改完能看到了。第二轮：点"记录"页，404。因为我用的是 `/history` 这种路径，静态托管没有服务器去处理路由，它只会去找 `history/index.html`。

第三轮：好不容易能点，刷新又 404。同一个原因。

最后我做了三个决定：

- 所有资源用相对路径（`./` 开头），不写绝对路径。
- 路由改成 `#/history` 这种 hash，浏览器不会把它发给服务器。
- 加一个 `.nojekyll` 空文件，告诉 GitHub Pages 别再拿 Jekyll 处理我的文件（不然下划线开头的目录会被忽略）。

这三个坑，加起来花了我一个下午，代码一行没写。

当时我有点沮丧，觉得这不是"写程序"。现在我的看法变了：**一个东西只有能被别人打开，才算做完。** 部署不是收尾动作，它是交付本身的一部分。

也是从这天起，我每做完一个东西，第一件事是发链接给自己手机，而不是继续加功能。
